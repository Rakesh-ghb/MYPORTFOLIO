# Rakesh Gorre Portfolio (React + Vite)

## Run on your computer
1. Install Node.js 18 or newer from https://nodejs.org
2. Open a terminal in this folder and run:
   npm install
   npm run dev
3. Open the address it prints (usually http://localhost:5173)

## Build for production
npm run build   (output goes to the dist folder)

## Deploy on Vercel
Push this folder to GitHub, then import the repo in Vercel. It detects Vite automatically.

## Edit your content
Change text, projects, experience and skills in src/data.js.
Project links: #/calculator and #/weather open the two apps.
